# dossier-epistemics Design

## Decision 1: lamps map to the locked trust ladder, stated in the UI

OBSERVED = evidence from execution: `vessel.behavior` present, or any
receipt-type anchor among the vessel's own entry anchors. VERIFIED =
entries whose stored trust is `measured` (direct source reading).
DECLARED = trust `charted` (manifests/BOM/packaging declarations).
CLAIMED = trust `reported` or `doubtful`. `unsurveyed` never counts into
any lamp — absence is absence. A footnote prints the mapping so the
labels cannot drift into folklore.

## Decision 2: derivations stay arithmetic over embedded fields

Sounded verdicts appear only when the stored fairway note contains
"sounded:" (the store itself records it); lamps count embedded entries;
no re-sounding, no inference beyond thresholds already used for roles.

## Decision 3: weaker tiers must name their carriers

CLAIMED > 0 renders the list of kind/ids inside that lamp's row — a
claim is only honest when you can see exactly what rides on it.

## Not here

Per-anchor sound.anchor verdict history (not stored per anchor in the
index); score numbers/aggregates beyond the four counters.
